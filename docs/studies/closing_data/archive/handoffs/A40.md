  cheap (7-class head, ~100 s/run). **Small states first** (AL/AZ = seconds), then FL, then CA/TX, then Istanbul.

> single-task `--task next` run has one param group and `train.py` **hard-errors** on `--cat-lr` alone
> (`--cat-lr/--reg-lr/--shared-lr must all be set together`). The faithful single-task match to the MTL v17 cat lever
> (cat group peaks at `--cat-lr`=1e-3 under `--onecycle-per-head-lr`; the recipe's `--max-lr 3e-3` is **ignored** for the
> cat group) is **OneCycle peak `--max-lr 1e-3`, `--batch-size 8192`**. NB `default_next` `max_lr=0.01` (STL-next
> default), so `--max-lr 1e-3` *lowers* the cat-head peak to 1e-3 — this makes the honest Δcat **larger**, not smaller
> (v16 AL ceiling 55.87 @ peak 0.01 → v17 AL s0 53.67 @ peak 1e-3). The rundir's `lr1.0e-04` leaf is the unrelated base
> AdamW `learning_rate`, NOT the OneCycle peak, so v16 and v17 rundirs look identical — read the recipe, not the name.
> Driver: [`../archive/run_logs/h2_runs/run_h2.sh`](../archive/run_logs/h2_runs/run_h2.sh); collected JSONs → `docs/results/closing_data/h2_v17_cat_ceiling/`.
