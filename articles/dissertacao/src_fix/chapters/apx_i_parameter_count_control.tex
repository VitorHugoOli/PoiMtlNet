\chapter{A Parameter-Count Control for Next-Category Prediction}
\label{apx:parameter-count-control}

Chapter~\ref{ch:mobiwac} attributes the next-category results to the check-in-level
representation rather than to the size of the model that reads it. This experiment tests the
competing explanation. The dedicated category model was made wider until it had approximately the
same number of trainable parameters as the complete joint model, holding the representation, the
folds, and the training protocol fixed. If capacity were what the category task responds to, the
wider model should improve. It does not.

The control covers Alabama and California, chosen as the smallest and the largest of the five
U.S. datasets. It is an additional dissertation analysis and does not appear in the
Chapter~\ref{ch:mobiwac} manuscript.
Section~\ref{sec:conc:answer} uses it to test one alternative explanation for the
final result.

\section{Result at a glance}
\label{sec:apx-parameter-summary}

Table~\ref{tab:apx-parameter-comparison} places the three results side by side. At both datasets
the wider dedicated model scores below the narrower one it replaces, so roughly six times the
parameters buys nothing on this task. The joint model, which carries a comparable budget, lands
close to the narrow dedicated model rather than close to the wider one. Capacity is therefore not
the variable the category task responds to at either dataset, which leaves the representation as
the explanation Chapter~\ref{ch:mobiwac} gives.

The joint column uses the diagnostic-best category checkpoint, matching the
per-task convention of this control. Chapter~\ref{ch:mobiwac} instead uses one
jointly selected checkpoint for its headline table. Those values are not mixed here.

\section{Experimental design}
\label{sec:apx-parameter-design}

The control changes one factor: the hidden dimension of the dedicated
next-category model. Each setting uses four seeds, \{0, 1, 7, 100\}, and five
user-disjoint folds per seed, for 20 fitted models. The reported value is macro-F1
at the best macro-F1 epoch, averaged over those models.

Table~\ref{tab:apx-parameter-counts} shows the capacity match. The original model
uses a hidden dimension of 256. The wider models reach 100.2\% and 101.9\% of the
joint-model parameter counts, so they do not receive a smaller parameter budget.

\section{Interpretation and limits}
\label{sec:apx-parameter-result}

In these two datasets, parameter count alone does not explain the joint model's
advantage. The joint model uses architectural and joint-training mechanisms that
the wider dedicated model does not reproduce. This control cannot determine which
mechanism, or which combination of mechanisms, is responsible for the gain.

The scope is limited to next-category prediction in two of the six datasets, one
wider model per dataset, width rather than depth, and a smaller hyperparameter
search than the original model. The result rules out a simple parameter-count
explanation in this setting, but it is not a complete capacity study or a component
ablation.
