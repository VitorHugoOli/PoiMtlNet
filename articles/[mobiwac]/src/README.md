## Layout

`main.tex` is the root (IEEEtran conference class, US Letter). Prose lives in `sections/*.tex`
(eight files, `01_introduction` … `08_conclusion`), tables in `tables/*.tex` (three), figures in
`figs/` (`fig1_dataflow.tex` and `fig2_model.tex` are TikZ, `\input` inline; `fig4_deltas.tex`
includes `fig4_deltas.pdf`, generated by `fig4_deltas.py`; `fig3_embquality.*` is kept but is
**not** in the build and carries pre-v18 constants). Bibliography keys live in `references.bib`;
`IEEEtran.cls` and `IEEEtran.bst` are bundled so the paper compiles without a full IEEE install.

Every camera-ready edit carries a dated `%` comment beside it, placed **between sentences, never
inside one**: a comment inserted mid-sentence swallows the rest of the line into the comment and the
text disappears from the PDF with no error (it happened four times on 2026-09-06; the gate now
catches it).

## Build and gate

```sh
sh gate_v17.sh            # rebuilds (pdflatex, bibtex, pdflatex x2) and then checks the result
GATE_PHASE=2 sh gate_v17.sh   # same, plus the 8-page target and \IEEEpubid for the final cut
```

The gate exits non-zero if any number of the leaked v17 generation survives in the PDF or in the
source (comments included), if a retired phrase survives in live prose, if any of the 12 v18
cells is missing from the PDF, if the build has undefined references or citations, overfull boxes
or TeX errors, or if a comment sits mid-sentence. **Read its last line; a green build is not a
green gate.**

Page count on 2026-09-06: **11**. The venue allows 8 pages plus at most 2 paid pages (10 is the
ceiling). The cut to 8 is decided by the author and happens after every correction has landed.
Build artifacts (`*.aux`, `*.log`, `*.bbl`, …) are gitignored; the figure PDFs and `main.pdf` are
kept under version control.
